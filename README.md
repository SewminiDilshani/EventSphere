# EventSphere – Agent-Based Venue Booking and Digital Ticketing Platform

## 1. Project Overview

EventSphere is a mobile-friendly web application developed for the IT4123 Agent Based Computing Practical – ICA 02 assignment.

The system provides a single platform for university event management, ticket booking, digital ticket generation, QR-based check-in, and private venue hire.

The application supports three user roles:

- **Admin:** Manages venues, events, ticket categories, venue hire requests, and event activities.
- **Staff:** Scans and validates digital tickets at event entrances.
- **Attendee:** Browses events, books tickets, views bookings and tickets, and requests private venue hire.

The platform uses simulated payments only. No real bank, card, or payment gateway is connected.

## 2. Main Features

### User Accounts and Authentication

- User registration and login.
- Password hashing.
- Role-based access control.
- Admin, staff, and attendee roles.
- Session-based authentication and CSRF protection.

### Venue Management

- Create and manage venues.
- Store venue details, capacity, location, and hire information.
- Manage private venue hire availability.

### Event Management

- Create and manage events.
- Support draft and published events.
- Manage event details and ticket categories.
- Manage ticket prices and quantities.
- Check venue availability and scheduling conflicts.

### Ticket Booking

- Browse and view available events.
- Book event tickets.
- Prevent ticket overbooking.
- Simulated payment processing.
- Store payment references.
- View booking history.
- Cancel bookings according to the implemented cancellation policy.

### Digital Tickets and QR Check-in

- Generate unique QR codes for tickets.
- Display digital tickets to attendees.
- Scan tickets using a camera.
- Support manual ticket code entry.
- Validate ticket status and check-in information.

### Private Venue Hire

- Submit private venue hire requests.
- Select a venue, date, and time.
- Enter purpose and guest count.
- Calculate venue hire prices.
- Check venue availability.
- Allow administrators to manage pending requests.

### Dashboards

- Admin dashboard.
- Staff dashboard.
- Event and ticket management.
- Booking and check-in information.

## 3. Agent-Based Architecture

The system is designed around the following agents:

| Agent             | Main Responsibility                                                                 |
| ----------------- | ----------------------------------------------------------------------------------- |
| VenueAgent        | Manages venue availability, scheduling conflicts, and private venue hire decisions. |
| BookingAgent      | Handles ticket booking requests, availability checks, and cancellations.            |
| TicketAgent       | Generates and validates digital tickets and check-ins.                              |
| WaitlistAgent     | Manages customers waiting for available tickets.                                    |
| NotificationAgent | Handles notifications generated by system activities.                               |

**Agent communication:** The intended agent communication format uses structured messages containing a sender, receiver, performative, content, and conversation ID.

Supported performatives specified in the assignment:

- REQUEST
- AGREE
- REFUSE
- PROPOSE
- INFORM
- FAILURE

Refer to the implemented agent modules and message logs for the actual communication and decision rules.

## 6. Installation and Setup

### Prerequisites

Install the following:

- Python 3.11 or later
- Git
- Visual Studio Code (recommended)

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Move into the project directory:

```bash
cd EventSphere
```

### Step 2: Create a Virtual Environment

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.venv\Scripts\activate
```

### Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Configure Environment Variables

Create a `.env` file in the project root directory.

Example:

```env
ENVIRONMENT=development
SECRET_KEY=your_secret_key
DATABASE_URL=sqlite:///./eventsphere.db
```

Use a strong secret key. Never commit the `.env` file to GitHub.

### Step 5: Run the Application

```bash
uvicorn app.main:app --reload
```

Open the application:

```text
http://127.0.0.1:8000/
```

FastAPI API documentation:

```text
http://127.0.0.1:8000/docs
```

## 9. Running Tests

Install pytest:

```bash
pip install pytest
```

Run the test suite:

```bash
pytest -v
```

The test suite should cover:

- User authentication and role permissions.
- Ticket booking and availability.
- Concurrent booking and overbooking prevention.
- Ticket generation and validation.
- Double check-in prevention.
- Venue availability and scheduling conflicts.
- Private venue hire decisions.
- Agent communication and decision rules.
- Waitlist behaviour and expiry.
- Notification handling.

The final submission should include at least 10 meaningful passing Pytest tests, including at least one test for each required agent.
